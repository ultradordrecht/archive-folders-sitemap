# Archive Folders Sitemap

A WordPress plugin that adds configurable static archive folders to your WordPress sitemap.

## Installation

1. Upload to `/wp-content/plugins/`
2. Activate in WordPress admin
3. Go to Settings → Archive Folders
4. Enter your folder paths (one per line)

## Usage

Add folder paths like:
- `/static-website-1/`
- `/static-website-2/`

Folders will automatically appear in your sitemap at `/wp-sitemap.xml`
